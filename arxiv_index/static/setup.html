arXiv index · first-time setup

The index is empty. Choose the arXiv categories it should cover and the model that embeds them, then fill it: from arXiv's own metadata, or from an index exported by another instance.

Open this page on the machine running the server

Setting up moves large files between your browser and the index, so it is only offered there. On that machine, open the address serve printed, usually http://127.0.0.1:8000/.

1. Categories

Their full arXiv names, separated by spaces or commas, such as math.AG hep-th cs.LG (the list). A paper is included if any of its categories is one of these. More categories take longer to embed.

2. Embedding model

The model that turns abstracts and searches into vectors, from the ones installed in Ollama. The default, qwen3-embedding:4b, is the one this was tuned with. To use another, ollama pull it and reload this page. An index keeps its model for good.

3. Fill the index

From arXiv's snapshot
  1. Download the arXiv dataset from Kaggle (a free account is needed).
  2. Unzip it, and choose arxiv-metadata-oai-snapshot.json (about 5.5 GB).
Embedding is the long part: about three hours for three categories on a consumer GPU. It runs on the server, and search works as it goes.
From another instance
  1. There, use Export index under ⚙, or run python3 -m arxiv_index export.
  2. Choose the .tar file it made.
The embeddings come with it, so it is searchable at once. Its embedding model and categories come with it too, in place of the choices above; so do its followed authors and interests, if it was exported with its settings.
